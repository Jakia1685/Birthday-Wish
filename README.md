# Birthday-Wish

🎉 Birthday Surprise Web App

A simple and aesthetic Birthday Surprise website built using HTML, CSS and JavaScript.

Features

- 🎀 Beautiful pink surprise landing screen  
- 🎆 Fireworks animation on start  
- 🎂 Animated birthday cake  
- 🌹 Falling roses after wishing  
- 🎵 Music play/pause option  
- ✨ Smooth interactive UI  
- 💕 Name personalization (birthday wish)

Live Flow

1. Open the website  
2. Click on 'Surprise 💖'  
3. Fireworks animation starts 🎆  
4. Birthday page appears 🎂  
5. Enter name and click "Wish 🎂" 
6. Roses start falling 🌹  
7. Enjoy music & celebration 🎵  


Technologies Used

- HTML 
- CSS 
- JavaScript
